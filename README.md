# Personal Profile Website | Elman Touhid

A simple and responsive personal profile website introducing my background, technical skills, projects, and contact information.

## 📌 About the Project

This project was developed as part of my Software Development coursework. It serves as a personal profile website where visitors can learn about me, explore my technical interests, view selected projects, and contact me through an interactive contact form.

The website focuses on a clean layout, simple navigation, and a user-friendly experience.

## ✨ Features

- **About Me:** Introduction and academic background.
- **Profile Picture:** Personal profile photo.
- **Skills:** Overview of programming languages and technical skills.
- **Projects:** Showcase of selected projects.
- **Contact Information:** Direct email contact.
- **Contact Form:** Allows visitors to submit messages.
- **Database Integration:** Supabase integration for storing contact form submissions.
- **Responsive Layout:** Basic mobile-friendly styling.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| JavaScript | Contact form functionality |
| Supabase | Database integration |
| Git & GitHub | Version control |
